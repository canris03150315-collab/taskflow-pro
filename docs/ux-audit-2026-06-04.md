## Recommended fix order (top 5)

1. **KOLManagementView.tsx** — Three modals with no ESC/backdrop close and no `aria-modal`. Primary feature view used daily by the KOL operations team; all three modals trap focus with no keyboard exit. Fix: add a `useEffect` ESC listener + `onClick={onClose}` on the backdrop + `role="dialog" aria-modal="true"` to each modal. Replace `💰` heading emoji with `CurrencyDollarIcon`.

2. **PaymentModals.tsx** — Three modals with zero keyboard accessibility AND zero focus rings on every `<input>`. Used in financial workflows where data entry accuracy matters. Fix accessibility gap and add `focus:ring-2 focus:ring-blue-200` to all inputs in the same pass.

3. **LeaveManagementView.tsx** — Four modals without ESC/backdrop close, used by all employees for leave applications. Also has the most structural-emoji tab buttons — replace `📅`, `⚙️`, `📋` with `CalendarIcon`, `Cog6ToothIcon`, `ListBulletIcon` from Heroicons.

4. **AuditLogView.tsx + Revenue tabs batch** — Five files (AuditLogView, RevenueStatsTab, RevenueStatsTab-Detailed, RevenueHistoryTab, RevenueDateStatsTab) have systematic `gray-*` color usage and plain loading text. Batch fix with a single find-and-replace pass: `gray-50` → `stone-50`, `border-gray-200/300` → `border-slate-200`, `bg-gray-100 text-gray-700` → `bg-stone-100 text-slate-700`, then swap `載入中...` text nodes for inline spinner SVGs.

5. **DataCleanupView.tsx + ChangePasswordModal.tsx + DepartmentDataView.tsx** — Three smaller files each with 1-2 critical modal accessibility gaps (no `aria-modal`, no ESC). Small files, quick wins that complete the sweep of all un-accessible modals in the app.
