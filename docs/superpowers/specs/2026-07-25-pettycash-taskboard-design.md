## Feature A：零用金月結版（FinanceView）

**問題**：現況只有 個人/部門/全部 範圍篩選，無任何日期維度；統計是開帳以來總計。
按月報帳/對帳時要在整條流水裡肉眼找。

### A1 月份切換器
- 位置：PETTY_CASH 分頁頂部、統計卡上方。
- 形式：`‹ 2026年7月 ›`＋「本月」快速鍵＋「全部期間」切換 chip。
- 預設＝當月。狀態 `filterMonth: string | null`（`'2026-07'` 格式；null＝全部期間）。
- 切月重置分頁 visibleCount。

### A2 當月統計
- 現有收入/支出/結餘統計卡改吃「月份篩選後」的 filteredRecords（月份篩選在範圍篩選之前套用）。
- 「全部期間」模式時行為同現況。

### A3 分類小計
- 當月（或全部期間）**支出**按 category 加總，列出：分類名、金額、CSS 橫條、佔比%。
- 由大到小排序；點分類＝toggle 篩選清單（再點取消）；空資料月份顯示空狀態文案。
- 純 CSS bar，不引入圖表庫。

### A4 CSV 匯出
- 按鈕「匯出本月 CSV」（全部期間模式時文案「匯出全部」）。
- 內容＝目前篩選結果（月份＋範圍＋分類篩選後）；欄位：日期、類型、分類、說明、金額、狀態、部門、記錄人。
- **UTF-8 BOM** 開頭（Excel 中文防亂碼）；檔名 `零用金_2026-07.csv`。
- client-side Blob 下載，一鈕一事（不自動開啟）。

### A5 細節規範
- 金額 `tabular-nums` 等寬對齊。
- 空月份 empty state：「這個月沒有紀錄」＋切回本月按鈕。
- 手機寬度：月份切換器不換行、分類條可收合（>5 類收成「更多」）。

## Feature B：任務看板升級（App.tsx tasks 頁 + TaskCard）

**問題**：單欄卡片流，看不出緊迫度、狀態結構、無人員/緊急度篩選、無節奏總覽。

### B1 統計列
- 4 個 chip：進行中 N、待接取 N、⚠ 逾期 N、本週完成 N。
- 點擊 chip＝套用對應快速篩選（再點取消）；逾期 chip 紅色系。
- 「逾期」定義：`deadline < today` 且 status 非 Completed/Cancelled。
- 「本週完成」：status=Completed 且完成時間在本週（週一起算）。
  Task 無 completedAt 欄位 → 以「最後一筆 timeline entry 的 timestamp」當完成時間；
  無 timeline 的已完成任務不計入本週數（仍計入已完成分組）。

### B2 篩選器列
- 下拉 ×3：負責人、部門、緊急度；與現有搜尋、四個 tab 疊加（AND）。
- 有篩選時顯示 active chips＋「清除」；SPA state 保存在 App state（頁面切換回來仍在）。

### B3 狀態分組區塊（不做拖拉 kanban）
- 「總覽」tab 內卡片依狀態分組：進行中 → 已指派 → 待接取 → 已完成（最近 10 筆）。
- 每組 sticky 小標＋數量；桌機組內 2 欄 grid、手機單欄。
- 改狀態沿用卡片現有按鈕；不做拖拉（手機難用＋工程大，YAGNI）。
- 其他 tab（我的/待接取/已封存）維持平鋪列表＋新篩選器生效。

### B4 期限 chip（TaskCard）
- 逾期＝紅「逾期 N 天」；48 小時內＝橘「明天到期/今天到期」；其餘灰色短日期；無期限不顯示。
- **實作前先檢查 TaskCard 現有 deadline 顯示，擴充既有元素、不疊第二套**（防新舊並存）。

### B5 排序
- 預設改「截止日近→遠」（無期限沉底）；下拉可切：截止日／建立日新→舊／緊急度高→低。
